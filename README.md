# GameVault

GameVault, oyun dünyası için wiki, rehber, güncelleme notları ve topluluk yorumları sunan modern bir web sitesidir.

## Özellikler
- Ana sayfa
- Wiki / makale sayfası
- Rehberler sayfası
- Güncelleme notları sayfası
- SSS / FAQ sayfası
- Yorum sistemi
- Mobil uyumlu tasarım

## Çalıştırma
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
